# Shreyaa Birthday Experience

A responsive, romantic birthday website starter with:
- Luxury rose, pink, plum, and gold styling
- Intro overlay and animated background
- Continuously looping ribbon, orbit, particles, floating hearts, candle flame, and subtle glows
- Wishes, memory gallery, birthday letter, cake wish interaction, and surprise reveal
- Responsive navigation and reduced-motion accessibility support
- Optional background music (bring your own audio file)

## Run it
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code with Live Server.
3. Add Shreyaa's photo as `assets/images/shreyaa.jpg` if you want to replace the hero placeholder. The current hero uses a styled placeholder, so no photo is required to run.
4. Add a song you have permission to use at `assets/music/birthday-song.mp3`. The music button will explain if no file exists.

## Customize
- Change the message text in `index.html`.
- Add photos to the gallery by replacing `.memory-image` placeholder blocks with `<img src="assets/images/your-photo.jpg" alt="Description">`.
- CSS animations and responsive layout are in `css/style.css`.
- Interactions are in `js/script.js`.

The clock shows the current local time; it is not a birthday countdown because no birthday date was supplied.
